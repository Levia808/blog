08 · 断点规范

响应式规则总表

断点变化
≤ 900px文章 TOC 侧栏移至正文底部（非 sticky）· 文章布局单列
≤ 820px管理面板：左导航折叠为顶部横向滚动 · 统计 2 列 · 面板内边距收窄
≤ 768px桌面导航隐藏 → 汉堡菜单 · 页脚单列居中 · 文章卡片内边距收窄 · 搜索浮层上移
≤ 640px文章卡片网格 3/2 列 → 单列 · 动态媒体 2 列保持 · 归档条目换行
≤ 480px统计卡 2 列 → 保持 · 终端欢迎页高度 40vh · 字号微降
全局触控目标 ≥44px · 按钮间距 ≥8px · 水平溢出滚动（表格/导航）· 禁 hover 依赖（触摸）
无障碍正文对比 ≥4.5:1 · 大字号 ≥3:1 · :focus-visible 苔绿环 · aria-label 补足
安全区底部 padding 适配 iOS 手势条 (env(safe-area-inset-bottom)) · 顶部 sticky 导航含状态栏间隙
触控目标链接/按钮/输入最小 44×44px；图标按钮 40px+
单列优先内容全宽，最大行宽 640px 内自然阅读
折叠优先TOC/表格/导航均折叠或横向滚动，不挤压内容
hover 降级触摸设备交互以 :active + 过渡替代 hover
移动优先min-width 渐进增强 · 桌面复杂度在 ≥768px 叠加
ASCII 语法mono 元数据统一 [ ] 方括号 / ▸ / >/> 前缀装饰
直角纪律radius ≤2px · gap:1px 生成微细分割线 · 无阴影无渐变
