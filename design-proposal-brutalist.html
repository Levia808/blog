02 — 设计哲学

新粗野主义五大法则

⬛
粗黑边框

3-4px solid #000 是所有元素的默认边框。没有 hairline，没有半透明。

■
实心阴影

box-shadow 无模糊半径。6px 6px 0 #000。实体投射，像纸片堆叠。

🎨
高饱和撞色

亮黄 + 亮粉 + 黑 + 奶油白。一组不超过 5 个主色，饱和度拉满。

📄
粗重排版

Space Grotesk 700-900 weight。大字号、紧字距、无衬线。标题比正文大 3-5 倍。

DO ✅
  • ■ 3px+ 实线黑边
  • ■ 无模糊硬阴影
  • ■ 互斥高饱和色
  • ■ 不对称/打破网格
  • ■ 大字号 + 紧字距
  • ■ 碰撞式排版
  • ■ 故意"粗糙"的角落
DON'T ❌
  • □ box-shadow blur
  • □ 半透明/渐变边框
  • □ 圆角 > 12px
  • □ 低对比度低饱和色
  • □ 标准 16px/1.5 排版
  • □ 对称居中一切
  • □ 精致阴影/玻璃效果

08 — 实施路径

从 PaperMod 到粗野主义

1
CSS 变量覆盖
在 assets/css/extended/ 注入粗野 CSS 变量。不修改 Hugo 模板，先改色系。
2
字体切换
加载 Space Grotesk + DM Sans（Google Fonts），替换 Inter 为标题字体。
3
组件粗野化
卡片、按钮、标签、导航逐一应用 3px 边框 + 硬阴影规则。
4
布局打破
引入不对称栅格、偏移 Hero、打破居中对齐。添加装饰星形/箭头。
⚡ 关键文件映射：
assets/css/extended/design-system.css → CSS 变量 + 全局样式
assets/css/extended/animations.css → hover 效果
layouts/partials/header.html → 导航栏
layouts/partials/auth-modal.html → 登录弹窗粗野化
hugo.yaml → 字体配置 (Google Fonts params)
