.05/motion

动效设计系统

暗色酸性风格的动效哲学：锋利 · 瞬时 · 机械 · 荧光。不使用弹性/回弹/渐进柔和曲线——一切都应该是锐利、终端般的响应。

[motion_principles]
  • ■ 过渡时长 ≤ 150ms
  • ■ ease-out / step-end 为主
  • ■ 禁用 spring / bounce / elastic
  • ■ hover → 立即反色或边框变色
  • ■ 页面切换 → 无过渡或淡入
  • ■ 滚动揭示 → 简单 fade-up (50ms delay)
  • ■ loading → 闪烁光标 + typewriter
[timing_tokens]
--dur-instant: 50ms // 边框闪变
--dur-fast: 100ms // hover 反馈
--dur-normal: 150ms // 展开/折叠
--dur-slow: 300ms // 模态进出

.07/article-page

文章详情页布局

blog-go3.pages.dev/posts/hello-world — 文章详情
[POST] 2026-08-06 · 5 min · TAGS: [hugo] [cloudflare] [devops]
构建现代化个人博客
从 Hugo 静态站点生成器到 GitHub Pages + Cloudflare Pages 双线部署的完整实践指南。

本文将带你一步步搭建一个支持 GitHub OAuth 登录、Supabase 评论系统、Fuse.js 全文搜索的现代化个人博客。

1. 为什么选择 Hugo

Hugo 是 Go 语言编写的静态站点生成器，构建速度极快（22 个页面仅需 43ms），天然支持 Markdown、多语言、自定义布局。

// hugo.yaml — 一行命令搞定构建
baseURL: https://blog-go3.pages.dev/
theme: PaperMod
locale: zh-cn

2. 双线部署策略

GitHub Pages 用于海外访问，Cloudflare Pages 用于国内加速。一次 push，两边自动构建。

部署的本质不是"放在哪里"，而是"如何让内容最快到达读者"。—— 双 CDN 策略的核心

以上展示了一个完整文章页面的排版结构：代码块带左绿边、引用块带左粉边、正文内链带酸性绿下划线。
