▶ motion-rule
唯一允许的 opacity 变化：页面首屏 fade-up 进入动画。此后所有交互反馈仅使用 transform。色彩和透明度在整个交互生命周期中保持不变。这创建了一种物理质感——元素像有质量的物体一样移动，而不是像 LED 屏幕一样闪烁。

▶ scroll-aware-nav.js
trigger: scroll delta > 60px
↓ 下滑: nav → translateY(-100%) · 250ms ease-out · 隐藏为内容腾空间
↑ 上滑: nav → translateY(0) · 250ms ease-out · 立即浮现
顶部: 始终显示 (scrollY < 60px 时强制 visible)
实现: position: sticky; top: 0 + JS 监听 scroll 切换 .nav-hidden class
滚动方向scrollY 条件CSS class视觉时长
↓ 下滑> 60px delta.nav-hiddentranslateY(-100%) · 导航上滑消失250ms
↑ 上滑> 60px delta:not(.nav-hidden)translateY(0) · 导航滑入浮现250ms
↕ 顶部< 60pxforce visible始终可见 · 不参与隐藏逻辑—
— 静止delta < 60px保持当前状态无变化 · 避免微小滚动抖动—
scroll-nav.js
$ cat scroll-nav.js
const nav = document.querySelector('.nav-full');
let lastY = 0, ticking = false;
const DELTA = 60;

document.addEventListener('scroll', () => {
  if (!ticking) {
    requestAnimationFrame(() => {
      const y = window.scrollY;
      const delta = y - lastY;
      if (Math.abs(delta) > DELTA) {
        nav.classList.toggle('nav-hidden', delta > 0 && y > 60);
        lastY = y;
      }
      ticking = false;
    });
    ticking = true;
  }
});

$ █
▶ performance-note
使用 requestAnimationFrame 做节流，避免 scroll 事件阻塞主线程。position: sticky 确保导航在隐藏时仍占据布局空间（不引起 CLS）。仅在 delta 超过 60px 阈值时切换 class，消除手指微颤导致的闪烁。
