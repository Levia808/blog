终端美学 (概念)

酸性设计 × CLI界面
CRT 荧光 · ASCII 艺术 · 二进制 · 黑客美学
▶ insight.txt
暗色酸性粗野主义 = 粗野结构（硬边框、暴露栅格）+ 酸性色彩（荧光绿#39FF14 + 粉色#FF2D55）+ 扁平化（零阴影、零圆角、零渐变）。这一风格在中文技术博客领域几乎为空白——率先采用即是品牌。
.02/principles

六项设计法则

[01]
纯平无影

zero box-shadow · zero gradient · zero backdrop-filter · 纯 2D 平面

[02]
绝对直线

border-radius: 0 · 所有边角都是直角 · 无圆角温和化

[03]
深黑底色

#0A0A0A 纯黑画布 · #141414 卡片 · 极暗灰阶 · 高对比

[04]
酸性点缀

#39FF14 荧光绿 · #FF2D55 酸性粉 · #CCFF00 黄绿 · #00FFFF 电青

[05]
粗野结构

2-3px 实线边框 · 非对称布局 · 暴露网格 · 无装饰元素

[06]
终端审美

JetBrains Mono 代码级 · ▶ 提示符 · ASCII 装饰 · CLI 质感

▶ DO.txt
  • ■ 2-3px 实线单色边框
  • ■ border-radius: 0 全直角
  • ■ 0px box-shadow / 0px gradient
  • ■ #0A0A0A 底色 + 酸性 accent
  • ■ JetBrains Mono / Space Grotesk
  • ■ 非对称网格 + 打破居中
  • ■ CLI 提示符 / ASCII 装饰
▶ DON'T.txt
  • □ box-shadow（任何模糊）
  • □ linear/radial-gradient
  • □ border-radius > 2px
  • □ 低对比度低饱和色
  • □ 精致阴影/玻璃效果
  • □ 居中对称一切
  • □ 过度装饰的图标/插画

▶ verdict.txt
此方案在"新粗野主义"基础上融合酸性设计（荧光绿、终端美学、CRT 肌理）与纯扁平化（零阴影、零圆角、零渐变），形成一套独立、尖锐、高辨识度的暗色设计语言。在当前中文技术博客领域无直接竞品。
.08/implementation

实施路径

step_01
CSS 变量覆盖
在 assets/css/extended/ 注入暗色酸性变量。不改模板，先改色系。
step_02
字体切换
加载 Space Grotesk + JetBrains Mono + Noto Sans SC 替换 Inter。
step_03
组件酸性化
卡片、按钮、标签、导航逐一应用 2px 边框 + 全直角 + 酸性色规则。
step_04
终端装饰
添加 CLI 提示符、ASCII box-drawing 装饰、CRT scanline 覆盖层。
