▶ terminal-philosophy.txt
终端美学的核心不是炫技——是用系统语言讲故事。导航栏=文件路径。加载态=编译输出。404=kernel panic。RSS=/dev/feed。将整个博客体验包装成一个优雅运行的系统，而不是一个网页。
.03c/minimalism

极简克制 · 少即是多

暗色酸性风格容易"元素过载"——荧光绿处处都是反而失去冲击力。极简主义在这里的角色是约束酸性：80% 的极简黑底 + 15% 的结构线 + 5% 的酸性点缀。

[OVERLOADED — 拒绝]
✘ 每个卡片都有绿色边框
✘ 到处是 ASCII 装饰
✘ 所有文字都是荧光绿
✘ 5+ 种酸性色同时出现
✘ 按钮/标签/文字抢注意力
[RESTRAINED — 目标]
✔ 仅 Hero 用绿色边框
✔ ASCII 装饰仅页首/页尾
✔ 正文用 #EBEBEB 白色
✔ 每屏 ≤ 2 种酸性色
✔ 大量留白做视觉呼吸

▸ 80/15/5 配色分配法则

80% 黑底 · 留白
15% 结构
5% 酸性
▶ minimalism-rule.txt
酸性点缀像辣椒——一撮提味，半碗毁菜。一个页面上，酸性绿只应出现在 1-2 个元素上：当前导航项 + Hero 边框 + 或许一个 CTA 按钮。其他元素用暗色灰阶 + 白色文字，让那一点绿真正"亮"起来。

.04b/shape-radius

形状等级：圆角 vs 锐利

粗野主义不意味全直角——用形状差异暗示交互层级。结构元素保持锐利，可交互元素用微圆角。

类型border-radius示例元素理由
锐利 (Sharp)0section 边界 · 图块表 · 分割线 · 页脚 · 终端窗口结构框架 · 无需亲和力
微圆角 (Subtle)4-6px按钮 · 输入框 · Checkbox · 搜索框控件亲和 · 暗示可操作
圆角 (Rounded)8-12px文章卡片 · Hero 卡片 · Toast · 色板 · 模态内容容器 · 可点击区域
胶囊 (Pill)99px标签徽章 · 筛选 chip小型信息标签 · 高亲和
[SHARP 0px] — 结构卡片
Section · 页脚 · 表格
纯直角，传达"这是框架，不是可点击目标"。
[ROUNDED 8px] — 内容卡片
文章卡 · Hero · Toast
微圆角，传达"这是内容区块，可以交互"。
.CAPSULE 99px
▶ shape-philosophy.txt
圆角不是装饰，是功能信号。用户扫视页面时，看到的圆角 = 这是我能点/能输入的东西。锐利的元素 = 这是框架/结构/只读内容。这个等级系统让粗野主义既保留态度，又有现代 UI 的可读性。
.05/motion

动效设计系统

暗色酸性风格的动效哲学：锋利 · 瞬时 · 机械 · 荧光。不使用弹性/回弹/渐进柔和曲线——一切都应该是锐利、终端般的响应。

[motion_principles]
  • ■ 过渡时长 ≤ 150ms
  • ■ ease-out / step-end 为主
  • ■ 禁用 spring / bounce / elastic
  • ■ hover → 立即反色或边框变色
  • ■ 页面切换 → 无过渡或淡入
  • ■ 滚动揭示 → 简单 fade-up (50ms delay)
  • ■ loading → 闪烁光标 + typewriter
[timing_tokens]
--dur-instant: 50ms // 边框闪变
--dur-fast: 100ms // hover 反馈
--dur-normal: 150ms // 展开/折叠
--dur-slow: 300ms // 模态进出

Hugo 是 Go 语言编写的静态站点生成器，构建速度极快（22 个页面仅需 43ms），天然支持 Markdown、多语言、自定义布局。

GitHub Pages 用于海外访问，Cloudflare Pages 用于国内加速。一次 push，两边自动构建。

部署的本质不是"放在哪里"，而是"如何让内容最快到达读者"。—— 双 CDN 策略的核心
